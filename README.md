# Period Tracker App

A Python-based application built using Flet to help women and girls track their menstrual cycles.

## Features
- Track menstrual cycle dates
- Simple and user-friendly interface
- Helps users monitor and manage their health

## Technologies Used
- Python
- Flet (UI framework)

## How to Run
1. Install Python
2. Install dependencies:
   pip install flet
3. Run the app:
   python main.py

## Future Improvements
- Add notifications/reminders
- Store user data in a database
- Improve UI design
